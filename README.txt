🌟 FEATURE CLÉE: Génération de fiches propres

Quand tu scans une fiche manuscrite:
  1. OCR détecte chaque mot et sa position
  2. Analyse les couleurs du texte original
  3. **Redessine EXACTEMENT aux mêmes positions**
  4. Utilise police cursive "Caveat" (manuscrit propre)
  5. Génère version ultra-propre (type fiche d'exam)

Résultat: Fiche manuscrite → Fiche propre avec même layout et design!

Code: src/services/cleanCardService.js
